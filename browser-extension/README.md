# Service Abbreviation Converter browser extension

This Manifest V3 extension opens the hosted converter in a dedicated browser tab. It works in Google Chrome and Microsoft Edge using the same package.

## Test locally

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this folder.
4. Click the extension icon.

## Publish

Zip the contents of this folder (not the parent folder) and upload the ZIP to the Chrome Web Store Developer Dashboard and Microsoft Edge Add-ons Partner Center. Store publication requires developer registration, screenshots, a privacy policy URL, support details, and a justification for every permission.
